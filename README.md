# D-Bridge 설치 파일

DailyANR 레퍼런스를 찾고, YouTube 공식 플레이어로 비교해 듣는 데스크톱 앱 **D-Bridge**의 설치 파일을 배포하는 저장소입니다.

- 이 저장소에는 설치 파일과 자동 업데이트 정보만 있습니다. **소스 코드는 비공개**입니다.
- 앱을 쓰려면 **DailyANR 계정**이 필요합니다. https://dailyanr.com
- 받기: [Releases](../../releases/latest)
  - macOS 12 이상, Apple Silicon·Intel: `arm64.dmg`(Apple Silicon) 또는 `x64.dmg`(Intel) — Apple 공증을 받은 파일입니다.
  - 플러그인(VST3·Audio Unit), macOS 11 이상, Apple Silicon·Intel: `Plugin-macOS.pkg` — Apple 공증을 받은 설치 파일입니다. 지금 로그인한 사용자 폴더(`~/Library/Audio/Plug-Ins`)에만 설치합니다.
  - Windows (x64): `Setup.exe` — 아직 코드 서명이 없어 처음 실행할 때 「Windows의 PC 보호」 창이 뜰 수 있습니다. Windows 판은 Microsoft Store로 옮길 예정입니다.
- 설치한 앱은 새 버전을 스스로 확인하고 뒤에서 받습니다. 「다시 시작해서 업데이트」를 눌러야 바뀌며, 앱 메뉴의 「업데이트 자동 확인」으로 끌 수 있습니다.
- 재생은 YouTube 공식 플레이어로만 합니다. 음원을 내려받거나 녹음하지 않습니다.
